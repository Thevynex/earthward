# Pilot visual-detail increment

Generated pilot shells now add deterministic windows, one-block smooth-stone sidewalks adjacent to rasterized roads, and sparse iron/sea-lantern street lights. These improve orientation and visual readability while preserving the verified OSM footprint coordinates and one-metre world scale.

Facade repetition, three-metre shell height, road width and lamp placement are explicitly inferred placeholders. They are not claimed as surveyed real-world facade details. The implementation still requires an actual Minecraft client run before visual quality or performance can be reported.
